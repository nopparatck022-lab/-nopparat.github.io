1. หัวข้อที่สนใจ

แอปพลิเคชันคำนวณแคลอรีและวางแผนสุขภาพประจำวัน (Calorie & Health Planner)

เหตุผลที่สนใจ: เพื่อช่วยให้ผู้ใช้งานสามารถบันทึกและคำนวณพลังงานที่ได้รับจากอาหารในแต่ละวัน รวมถึงแนะนำกิจกรรมการออกกำลังกายที่เหมาะสมเพื่อรักษาสุขภาพ

2. Prompt ที่ใช้

ช่วยสร้าง Web Application ด้วย HTML, CSS และ JavaScript สำหรับคำนวณแคลอรีและวางแผนสุขภาพ โดยมีฟังก์ชัน: 1. คำนวณ BMR และ TDEE จากน้ำหนัก ส่วนสูง และอายุ 2. ช่องบันทึกรายการอาหารและคำนวณแคลอรีรวมต่อวัน 3. ดีไซน์หน้าเว็บให้สวยงามใช้งานง่ายแบบ Modern UI รองรับมือถือ
